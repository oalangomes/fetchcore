# Security policy

FetchCore is currently a technical preview. No response-time or long-term support guarantees are implied.

For a suspected security vulnerability, **do not publish exploit details, credentials, tokens or sensitive repository content in a public GitHub issue or PR**. If the repository offers **Security → Report a vulnerability**, use that private reporting channel. Otherwise contact the repository maintainer through a private contact route available on the maintainer's GitHub profile before disclosing details. If no private channel is available, do not post the report publicly.

When possible, provide an affected revision, reproduction steps using synthetic data, impact and recommended mitigations. Avoid uploading private corpora or production secrets. For ordinary non-sensitive bugs, use [public issues](https://github.com/oalangomes/fetchcore/issues).

FetchCore retrieval results are evidence candidates, not authority, and should always be scoped by authorized repository bindings and bounded source reads.
